# 국산모아 — 원재료까지 국산인 식품, 국내에서 만든 생활용품

빌드가 필요 없는 정적 사이트(HTML/CSS/JS)입니다. GitHub에 올리면 Vercel이 자동 배포합니다.

## 기준
| 구분 | 기준 | 시트에서 확인하는 칸 |
|---|---|---|
| 🍚 식품 | 원재료 100% 국산 | `원재료원산지`가 전부 한국 (한국·국산·국내산·대한민국 모두 인정) |
| 🧺 생활용품 | 국내 제조 | `제조국`이 한국 |

기준에 맞지 않거나 칸이 비어 있으면 **사이트에 나오지 않고** `/admin.html`에 이유가 표시됩니다.

## 상품 관리 = 구글 시트
1. `sheet-template.xlsx`(카테고리·보관·추천·노출 드롭다운 포함)를 구글 드라이브에 올려 **Google 스프레드시트로 열기** → **파일 → Google Sheets로 저장**
2. **파일 → 공유 → 웹에 게시** → **상품** 탭 → **쉼표로 구분된 값(.csv)** → 게시 → 주소 복사
3. `config.js`의 `sheetCsvUrl`에 붙여넣기
4. `/admin.html`에서 확인 (시트 수정 후 반영까지 최대 5분)

### 캡처 사진을 쉽게 올리는 방법: 구글 폼
시트 칸에 이미지를 직접 붙여넣으면 사이트에 **안 나옵니다**(CSV에는 글자만 담김). 대신 구글 폼을 쓰면 사진이 드라이브에 저장되고 링크가 응답 시트에 자동으로 들어갑니다.
1. 구글 폼 질문 제목을 시트 열 이름과 똑같이: `상품명`, `쿠팡링크`, `카테고리`(드롭다운), `원재료원산지`, `제조국`, `제품사진`(파일 업로드), `원산지사진`(파일 업로드) …
2. 응답 탭 → **Sheets에 연결** → 생성된 응답 시트를 웹에 게시(CSV)
3. 드라이브에 생긴 업로드 폴더(`폼이름 (File responses)`)를 **링크가 있는 모든 사용자(뷰어)**로 공유
4. 검수일을 비우면 폼 제출 날짜(타임스탬프)가 들어갑니다. 수정·숨김은 응답 시트에서 직접(노출 열 추가 가능)

### 시트 열 (1행 이름으로 찾음, 순서 무관)
| 열 | 필수 | 설명 |
|---|---|---|
| 상품명 | ✅ | 쿠팡 상품명 그대로 써도 됨 (용량·개수 포함) |
| 쿠팡링크 | ✅ | 파트너스 단축 링크 `https://link.coupang.com/a/...` |
| 카테고리 | ✅ | 이걸로 식품/생활용품이 정해짐. 목록은 `/admin.html` 또는 `products.js` 참고 |
| 원재료원산지 | 식품 ✅ | 예: `한국` (여러 개면 쉼표). 외국이 하나라도 있으면 제외 |
| 제조국 | 생활 ✅ | 예: `한국` |
| 검수일 | | 표시사항 확인한 날짜 `2026-11-16`. 카드에 "검수 날짜"로 표시 |
| 보관 | | `냉동`/`냉장`이면 사진에 배지 |
| 테마 | | 쉼표로 여러 개. 테마마다 홈에 가로 줄 생성 (시트에 처음 나온 순서) |
| 추천 | | `O`면 "에디터 추천" 줄 + 목록 맨 앞 |
| 제품사진 | | 구글 드라이브 공유 링크 그대로 OK |
| 원산지사진 | | 원재료 표시사항(생활용품은 제조국 표시) 사진. 상세에서 첫 번째로 크게 표시 |
| 브랜드 / 설명 / 태그 | | 태그는 쉼표 구분, 검색·홈 빠른검색에 사용 |
| 구분 | | `식품`/`생활`. 새 카테고리를 만들 때만 필요 |
| 노출 | | `X`면 숨김 |

### 사진 (구글 드라이브)
사진 우클릭 → 공유 → **링크가 있는 모든 사용자(뷰어)** → 링크 복사 → 시트에 붙여넣기.
폴더를 통째로 이렇게 공유해 두면 안에 넣는 사진은 따로 설정할 필요가 없습니다.

## config.js
| 항목 | 설명 |
|---|---|
| `sheetCsvUrl` | 게시한 시트 CSV 주소 (비우면 예시 상품) |
| `requestFormUrl` | "등록 요청" 구글 폼 (비우면 메뉴 숨김) |
| `reportFormUrl` | 상세의 "오류 제보" 버튼 구글 폼. `{name}`을 넣으면 상품명으로 채움 |
| `contactUrl` | "문의하기" (mailto:, 오픈채팅, 폼 등) |

## 주소 규칙 (공유용)
`#cat=frozen` 카테고리 · `#theme=김장 준비` 테마 · `#q=두부` 검색 · `#p=상품ID` 상품 상세 바로 열기

## 파일
`index.html`/`app.js`/`style.css` 화면 · `sheet.js` 시트 읽기·기준 검사 · `products.js` 기준·카테고리·예시 상품 · `admin.html` 확인 페이지
