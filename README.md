# 국산모아 — 국산 제품 큐레이션 + 쿠팡 파트너스

빌드가 필요 없는 정적 사이트입니다(HTML/CSS/JS). PC와 모바일 둘 다 지원합니다.

## 상품 관리 = 구글 시트
상품은 **구글 시트**에서 관리합니다. 시트를 고치면 사이트에 자동으로 반영됩니다(구글 캐시 때문에 최대 5분 정도 걸릴 수 있음).

### 처음 한 번 설정
1. `sheet-template.csv`를 구글 시트로 가져오기 (파일 → 가져오기 → 업로드)
2. **파일 → 공유 → 웹에 게시** → 상품 시트 선택 → 형식 **쉼표로 구분된 값(.csv)** → 게시 → 주소 복사
3. `config.js`의 `sheetCsvUrl`에 붙여넣고 사이트 배포
4. `/admin.html`을 열어 "시트 연결됨"이 뜨는지 확인

### 사진 올리기 (구글 드라이브)
1. 드라이브에 사진 업로드 → 사진 우클릭 → **공유 → 일반 액세스: 링크가 있는 모든 사용자(뷰어)**
2. **링크 복사** → 시트의 `제품사진` / `원산지사진` 칸에 그대로 붙여넣기 (사이트가 자동으로 이미지 주소로 바꿉니다)
3. `/admin.html`에서 사진이 "안 보임"이면 공유 설정을 다시 확인

사진과 구매 버튼을 누르면 모두 쿠팡 파트너스 링크로 이동합니다.

### 시트 열 (1행 헤더 이름으로 찾음, 순서 무관)
| 열 | 필수 | 설명 |
|---|---|---|
| 상품명 | ✅ | |
| 쿠팡링크 | ✅ | 쿠팡 파트너스 단축 링크 `https://link.coupang.com/a/...` |
| 브랜드 | | |
| 카테고리 | | 식품·주방·생활용품·뷰티·건강·문구. 새 이름을 쓰면 카테고리가 자동으로 생깁니다. 비우면 "기타" |
| 설명 | | 상세 팝업에 표시 |
| 태그 | | 쉼표로 구분, 검색에 사용 |
| 추천 | | `O`면 상단 "에디터 추천"에 노출 |
| 원산지확인 | | `O`면 "✓ 원산지 확인" 배지 |
| 제품사진 | | 사진 주소 또는 구글 드라이브 공유 링크. 비우면 이모지 |
| 원산지사진 | | 국산 원재료·원산지 표기 사진. 카드에 작게, 상세에 크게 표시 |
| 이모지 | | 비우면 카테고리 기본 이모지 |
| 노출 | | `X`면 사이트에서 숨김 (행 삭제 없이 내리기) |

- 사이트에 나오는 순서는 시트의 행 순서와 같습니다.
- 링크가 없는 행은 건너뛰고, 파트너스 단축링크가 아닌 행은 `/admin.html`에 경고가 뜹니다.
- 시트를 불러오지 못하면 마지막으로 불러온 내용을, 그것도 없으면 `products.js` 예시 데이터를 보여줍니다.

## 파일
- `config.js` : 시트 주소 설정
- `sheet.js` : 시트(CSV) 읽기·변환
- `admin.html` : 연결 상태, 문제 있는 행, 표시될 상품 목록 확인
- `sheet-template.csv` : 시트 양식
- `products.js` : 카테고리 기본값 + 시트 연결 전 예시 데이터
- `index.html` / `app.js` / `style.css` : 사이트 화면

## 로컬에서 보기
```bash
python3 -m http.server 8080
```
→ http://localhost:8080

## 배포 (무료)
- **Netlify / Vercel / Cloudflare Pages / GitHub Pages**: 폴더를 그대로 올리면 됩니다(빌드 명령 없음).
- 도메인 연결 후 쿠팡 파트너스에 사이트 URL을 등록하세요.

## 꼭 지킬 것
- 쿠팡 파트너스 고지 문구("이 사이트는 쿠팡 파트너스 활동의 일환으로…")는 지우지 마세요. 공정위 지침상 필수입니다. 이미 상단, 하단, 구매 버튼 아래에 들어가 있습니다.
- 외부 링크에는 `rel="sponsored nofollow"`가 붙어 있습니다.
