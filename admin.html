확인이 필요한 행

    사이트에 표시되는 상품

    이미지상품명브랜드카테고리추천원산지확인쿠팡링크

    처음 설정하는 법

    1. 시트 양식(CSV) 내려받기 → 구글 시트에서 파일 → 가져오기 → 업로드
    2. 1행 헤더는 그대로 두고, 2행부터 상품을 입력 (상품명, 쿠팡링크만 필수)
    3. 파일 → 공유 → 웹에 게시 → 상품 시트 선택, 형식 쉼표로 구분된 값(.csv) → 게시 → 주소 복사
    4. 복사한 주소를 config.js의 sheetCsvUrl에 붙여넣고 사이트 다시 배포

    시트를 고친 뒤 사이트에 반영되기까지 구글 쪽 캐시 때문에 최대 5분 정도 걸릴 수 있습니다.
